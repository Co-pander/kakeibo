# 家計簿アプリ（v3.0.0）

シンプルな家計簿PWA。GitHub Pagesで公開し、スマホのホーム画面に追加して使う。

## ファイル構成

| ファイル | 役割 |
|---|---|
| `index.html` | 画面構造（HTML）のみ。約42KB |
| `style.css` | 全スタイル |
| `app.js` | 全ロジック（データ管理・描画・PIN・チャート等） |
| `manifest.json` | PWAマニフェスト（アプリ名・アイコン定義） |
| `sw.js` | Service Worker（オフライン対応・キャッシュ管理） |
| `app-icons/` | アプリアイコン（512px通常版・maskable版・iOS用180px・favicon） |

## 公開（デプロイ）方法

**上記ファイルすべて**（`app-icons/`フォルダ含む）を公開用リポジトリにアップロードする。
v2までの「index.html 1ファイルだけ」とは違うので注意。

## 更新時の手順

1. コードを修正する
2. `app.js` の `APP_VERSION` を上げる（例: `'3.0.0'` → `'3.0.1'`）
3. `sw.js` の `CACHE_NAME` も同じ番号に上げる（例: `'kakeibo-v3.0.1'`）
4. 変更したファイルをアップロード

Service Workerは「ネットワーク優先」なので、オンラインなら次回起動時に自動で最新版になる。
オフライン時のみキャッシュから表示される。

## 設計メモ

- **データ保存**: すべて端末内の `localStorage`（キー: `kb-v5`）。サーバー送信は一切なし
- **XSS対策**: ユーザー入力（メモ・名前等）をHTMLに埋め込む箇所は必ず `esc()` を通す。
  インラインonclick内のJS文字列には `escAttr(escJs(...))` を使う
- **CSP**: `index.html` のmetaタグで外部スクリプト・外部接続をブロック
- **PIN**: PBKDF2（ソルト付き・15万回反復）でハッシュ化して保存。
  旧形式（無ソルトSHA-256）のPINは解除成功時に自動で新形式へ移行
- **破損対策**: 読み込み時にデータが壊れていた場合は `kb-v5-broken` に退避してから初期化
- **アイコン**: maskable版は画像の周囲に余白を入れてあり、Android側のマスクで切れない

## ローカルでの動作確認

```
python -m http.server 3000
```

を実行して http://localhost:3000 を開く（Service Worker・PWA機能はhttpサーバー経由でないと動かない）。
